# 02 - VS Code Setup

- Download Brave / Chrome Browser

## Open folder in VS Code

- Open VS Code -> File => Open Folder
- Pc => Folder (Right Click) => Open with Code

## Extensions

- Live server (Ritvic Dey)
- Github Copilot
- Material Icons
- Github Themes
- Best themes (Dark +)

## Shortcuts

- Ctrl + N => Open new untitled file.
- Ctrl + C => Copy
- Ctrl + V => Paste
- Ctrl + L => Select current Line
- Ctrl + A => Select complete document Content
- Ctrl + Tab => Switch Tabs
- Alt + Tab => Switch Windows
- Key Binding -> Ctrl + CapsLock => Format Code
- Ctrl + / => Comment/Uncomment
- Ctrl + Shift + P => Preferences

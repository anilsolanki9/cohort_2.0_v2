SCSS (Syntactically Awesome Style Sheets)

1. Variable

We can create variales using $, eg. $primary, and use it as value like $primary. Variables can take value like - color (#0000ff), Size (70px), String (Arial, sans-serif), Boolean (true, false), Lists (Arial, Helvetica, sans-serif), Maps (multiple key-value pairs in { })

Variables also has scope (global, or local), In a scope, Local variables dominates global variables.

        
          $primary: #2563eb;
          $spacing: 20px;
          $font: Arial, sans-serif;

          .button {
          background: $primary;
          padding: $spacing;
          font-family: $font; 
          }

We can use !global to change the value of a global variable in local scope.

        
          $color: red;

          .box {
            $color: blue !global;
          }

CSS Variables remains in Browser and are determined on runtime, Whereas SCSS Variables are different. Thus we use combination of both CSS and SCSS. #{$primary} This is Interpolation, It tells SASS, Insert the SCSS variable value here. 

        
          $primary: #2563eb;
          $secondary: #9333ea;

          :root {
            --primary: #{$primary};
            --secondary: #{$secondary};
          }

2. Nesting

In SCSS, you can nest your CSS the same way your HTML is structured

        
          nav {
            background: black;

            ul {
              list-style: none;

              li {
                display: inline-block;

                a {
                  color: white;
                  text-decoration: none;
                }
              }
            }
          }

3. The & Parent Selector

The & in nested rule set, denote the current parent selector.

        
          .button {
            &:hover {
              background: black;
            }
          }

The & with Modifiers

        
          .button {
            background: blue;

            &--large {
              padding: 20px;
            }

            &--small {
              padding: 5px;
            }

            &--danger {
              background: red;
            }
          }

Produces

        
          .button {
            background: blue;
          }

          .button--large {
            padding: 20px;
          }

          .button--small {
            padding: 5px;
          }

          .button--danger {
            background: red;
          }

4. Mixins

A mixin is like a "reusable piece of code." If you find yourself writing the same CSS again and again for example, Flexbox centering you can save it as a mixin.

        
          @mixin box($width, $color) {
            width: $width;
            background: $color;
          }

          .card {
            @include box(200px, #ff6347);
          }

5. Partials & Imports

So SCSS allows you to split your styles into small files called partials. Partial files start with Underscore ( _ ) . Example, _header.scss, _footer.scss. And use them like

          
            @import "header";
            @import "footer";

Or if files are placed in folders like, components/_button.scss, button/_card.scss, Then

        
          @use "components/button";
          @use "components/card";

6. Built-in Functions

SCSS has some in-built color tools that make design tweaks super easy.

          
            lighten($color, 20%); // makes the color lighter 
            darken($color, 10%); // makes the color darker 
            mix(#ff0000, #0000ff,50%); // mixes two colors

7. @if{...} @else {...}

SCSS can perform logics.

        
          $dark-mode: true;

          body {
            @if $dark-mode {
              background: black;
              color: white;
            } @else {
              background: white;
              color: black;
            }
          }

8. Loops @for {...}

SCSS can generate CSS automatically. #{$i} this part is Interpolation.

        
          @for $i from 1 through 5 {
            .margin-#{$i} {
              margin: $i * 5px;
            }
          }
          // Generates
          .margin-1 {
            margin: 5px;
          }
          .margin-2 {
            margin: 10px;
          }
          .margin-3 {
            margin: 15px;
          }
          .margin-4 {
            margin: 20px;
          }
          .margin-5 {
            margin: 25px;
          }

9. Maps

Maps are basically key/value collections.

        
          $colors: (
            primary: #2563eb,
            success: #16a34a,
            danger: #dc2626,
            warning: #f59e0b
          );

          .button {
            background: map-get($colors, primary);
          }

          // If we use this
          @use "sass:map";

          // Then we use map.get(), Instead of map-get()
          .button {
            background: map.get($colors, primary);
          }

10. Functions

SCSS lets you create your own functions.

        
          @function double($number) {
            @return $number * 2;
          }

          .box {
            width: double(100px);
          }
